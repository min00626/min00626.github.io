## 프로젝트 개요

Project R은 높은 커스터마이징 자유도와 다양한 컨텐츠를 제공하는 서브컬쳐 MMORPG입니다.

메인 스토리와 서브 퀘스트를 중심으로, 낚시와 같은 미니게임, PVE 및 PVP 등 다양한 플레이 경험을 제공합니다.

## ADV Tool

ADV 툴은  **대화문과, 대화문에 연결된 연출을 편집하기 위한 커스텀 에디터 툴**입니다. ADV 툴은 기능에 따라 크게 두 부분으로 나눌 수 있습니다.
1. **ADV 그래프**  
대화문을 그래프 형태로 편집합니다.
2. **ADV 타임라인**  
각 대화문에 연결된 연출을 편집합니다.

#### 데이터 모델 구조

ADV 그래프의 각 노드 모델은 개별 `ScriptableObject`로 구성되며, 그래프 모델의 서브애셋으로 관리됩니다.  
<div class="mermaid">
flowchart LR
    Graph[AdvGraphModel]

    subgraph Nodes[Sub Assets]
        Node1[AdvNodeModel]
        Node2[AdvNodeModel]
        Node3[AdvNodeModel]
    end

    Graph --> Nodes
</div>

이러한 구조를 채택한 이유는 다음과 같습니다.

1. **Undo 처리 단위 최적화**  
   `Undo.RecordObject` 호출 시 그래프 전체가 아닌 노드 단위로 기록할 수 있어, 에디터 비용이 감소하고 변경점을 직관적으로 기록할 수 있습니다.

2. **SerializedObject 기반 에디터 확장성**  
   각 노드 모델을 `SerializedObject`로 직접 다룰 수 있어, 프로퍼티 단위 편집과 노드 뷰 구현이 용이합니다.

3. **에디터 디버깅 및 가시성**  
   각 노드 모델을 인스펙터에서 직접 확인할 수 있어 디버깅과 유지보수가 용이합니다.

### ADV 타임라인

ADV 그래프의 각 대화문 노드에는 타임라인 애셋이 연결되어 있습니다. 타임라인 애셋을 편집하여 대화문 출력 시 재생될 연출을 편집할 수 있습니다.

연출 편집을 위해 다양한 커스텀 트랙 및 마커를 제공합니다. ADV 타임라인에서 제공하는 기능은 다음과 같습니다.

1. 캐릭터 페이셜 및 애니메이션
2. 카메라 타게팅 및 애니메이션
3. 오브젝트 스폰 및 애니메이션
4. 페이드 인 / 아웃
5. BGM, SFX 재생 및 페이드
6. 포스트 프로세싱
7. 월페이퍼 연출

### 코드 샘플

다음 코드는 AdvGraphPresenter가 그래프를 그릴 때 호출되는 함수입니다.  
그래프 초기화 시 InitializeGraph가 호출되고, 그래프에 변경점이 발생하면 OnGraphViewChanged 함수가 호출됩니다.
<details markdown="1">
<summary>코드 보기</summary>

```csharp
    public partial class AdvGraphPresenter 
    {
        // ...

        private void InitializeGraph()
        {
            isInitializing = true;
            
            groupMap.Clear();
            nodeMap.Clear();
            edgeMap.Clear();
            
            graphView.DeleteElements(graphView.graphElements);

            foreach (var group in graphModel.Groups)
            {
                var dataGraphGroup = new GroupView(this, group.Guid) { title = group.Title };
                dataGraphGroup.SetPosition(group.Rect);
                groupMap.Add(group.Guid, dataGraphGroup);
                graphView.AddElement(dataGraphGroup);
            }
            
            foreach (var node in graphModel.Nodes)
            {
                NodeViewBase editorNode = CreateNodeView(node);
                editorNode.SetPosition(node.Position);
                nodeMap[node.Guid] = editorNode;
                graphView.AddElement(editorNode);
                
                // 그룹에 속한 노드인 경우 그룹에 추가
                if (!string.IsNullOrEmpty(node.GroupId) && groupMap.TryGetValue(node.GroupId, out var group))
                {
                    group.AddElement(editorNode);
                }
            }
            
            foreach (var dataGraphEdge in graphModel.Edges)
            {
                var outputPort = GetPortFromEdge(dataGraphEdge.outputPort.nodeId, dataGraphEdge.outputPort.portId);
                var inputPort = GetPortFromEdge(dataGraphEdge.inputPort.nodeId, dataGraphEdge.inputPort.portId);
                if (outputPort != null && inputPort != null)
                {
                    var edge = outputPort.ConnectTo(inputPort);
                    edgeMap[edge] = dataGraphEdge;
                    graphView.AddElement(edge);
                }
            }
            
            CreateStartNode();
            
            isInitializing = false;
        }

        public GraphViewChange OnGraphViewChanged(GraphViewChange graphViewChange)
        {
            // Undo에서도 트리거되는데, Undo 중인 경우 무시
            if (Undo.isProcessing || isInitializing) return graphViewChange;
            
            if(graphViewChange.elementsToRemove != null)
            {
                var elements = graphViewChange.elementsToRemove;

                // 엣지를 먼저 삭제해야 엣지 정리 로직 수행 가능
                foreach (var edge in elements.OfType<Edge>())
                    RemoveEdge(edge);

                // 2순위 : 노드
                foreach (var node in elements.OfType<NodeViewBase>())
                    RemoveNode(node);

                // 3순위 : 그룹
                foreach (var group in elements.OfType<GroupView>())
                    RemoveGroup(group);
            }

            if (graphViewChange.movedElements != null)
            {
                foreach (var element in graphViewChange.movedElements)
                {
                    switch (element)
                    {
                        case NodeViewBase editorNode:
                            editorNode.Model.SetWithUndo(() =>
                            {
                                editorNode.Model.Position = editorNode.GetPosition();
                            }, "Node Moved");
                            break;
                        case GroupView group:
                        {
                            var groupData = graphModel.Groups.FirstOrDefault(g => g.Guid == group.Guid);
                            if (groupData != null)
                            {
                                graphModel.SetWithUndo(() =>
                                {
                                    groupData.Rect = group.GetPosition();
                                }, "Group Moved");
                            }

                            // 그룹에 속한 노드들의 위치도 업데이트
                            foreach (var editorNode in group.containedElements.OfType<NodeViewBase>())
                            {
                                editorNode.Model.SetWithUndo(() =>
                                {
                                    editorNode.Model.Position = editorNode.GetPosition();
                                }, "Node Moved");
                            }
                            break;
                        }
                    }
                }
            }

            if(graphViewChange.edgesToCreate != null)
            {
                foreach (Edge edge in graphViewChange.edgesToCreate)
                {
                    AddEdge(edge);
                }
            }
            
            SetAssetDirty();

            return graphViewChange;
        }
        
        // ...
    }
```

## 로컬 데이터 저장 시스템

DB 대신 로컬에 저장할 간이 데이터를 저장 및 로드하는 시스템입니다.  
각 데이터는 `PersistentDataPath`에 바이너리 형태로 저장됩니다.

<br/>

### 바이너리 변환

로컬 저장이 필요한 클래스는 해당 클래스를 어떻게 바이너리로 변환할지 정의해야 합니다.  
이는 `IBinarySerializer` 인터페이스를 구현하는 클래스로 정의할 수 있습니다.

```csharp
    public interface IBinarySerializer<T>
    {
        void Write(BinaryWriter bw, T item);
        T Read(BinaryReader br);
    }
```

<br/>

다음 예시는 `ushort`, `ulong`, `long` 데이터를 가지는 클래스의 `BinarySerializer`입니다.  

```csharp
    public sealed class NotifyEntrySerializer : IBinarySerializer<NotifyEntry>
    {
        public static readonly NotifyEntrySerializer Instance = new();

        private NotifyEntrySerializer() { }

        public void Write(BinaryWriter bw, NotifyEntry item)
        {
            bw.Write(item.Category);
            bw.Write(item.ID);
            bw.Write(item.ObtainedTicks);
        }

        public NotifyEntry Read(BinaryReader br)
        {
            ushort category = br.ReadUInt16();
            ulong id = br.ReadUInt64();
            long ticks = br.ReadInt64();
            return new NotifyEntry
            {
                Category = category,
                ID = id,
                ObtainedTicks = ticks
            };
        }
    }
```

### 코드 샘플

다음 코드 블록은 Write, Read 로직의 구현부입니다.
<details markdown="1">
<summary>코드 보기</summary>

```csharp
private static SemaphoreSlim GetFileLock(string path)
    => _fileLocks.GetOrAdd(path, _ => new SemaphoreSlim(1, 1));

// ================= Write =================

private static void WriteSync<T>(string path, IReadOnlyList<T> items, IBinarySerializer<T> serializer)
{
    EnsureInitialized();

    var fileLock = GetFileLock(path);
    fileLock.Wait();

    string tmpPath = path + ".tmp";

    try
    {
        WriteCore(tmpPath, items, serializer, CancellationToken.None);

        PromoteTempFile(tmpPath, path);
    }
    catch (OperationCanceledException)
    {
        DeleteTempFileIfExists(tmpPath);
    }
    catch (Exception ex)
    {
        DeleteTempFileIfExists(tmpPath);
        LogUtil.Log($"LocalData WriteSync Error: {ex}".Color(Color.red));
    }
    finally
    {
        fileLock.Release();
    }
}

private static async UniTask WriteAsync<T>(string path, IReadOnlyList<T> items, IBinarySerializer<T> serializer, CancellationToken token)
{
    EnsureInitialized();

    var fileLock = GetFileLock(path);
    await fileLock.WaitAsync(token);

    string tmpPath = path + ".tmp";

    try
    {
        await UniTask.SwitchToThreadPool();

        token.ThrowIfCancellationRequested();

        WriteCore(tmpPath, items, serializer, token);

        token.ThrowIfCancellationRequested();

        PromoteTempFile(tmpPath, path);
    }
    catch (OperationCanceledException)
    {
        DeleteTempFileIfExists(tmpPath);
    }
    catch (Exception ex)
    {
        DeleteTempFileIfExists(tmpPath);
        LogUtil.Log($"LocalData WriteAsync Error: {ex}".Color(Color.red));
    }
    finally
    {
        fileLock.Release();
        await UniTask.SwitchToMainThread();
    }
}

private static void WriteCore<T>(string path, IReadOnlyList<T> items, IBinarySerializer<T> serializer, CancellationToken token)
{
    using (var fs = new FileStream(path, FileMode.Create, FileAccess.Write, FileShare.None))
    using (var bw = new BinaryWriter(fs))
    {
        bw.Write(items.Count);

        for (int i = 0; i < items.Count; i++)
        {
            token.ThrowIfCancellationRequested();
            serializer.Write(bw, items[i]);
        }

        bw.Flush();
        fs.Flush(true);
    }

    token.ThrowIfCancellationRequested();
}

private static void PromoteTempFile(string tmpPath, string finalPath)
{
    if (!File.Exists(tmpPath))
        throw new FileNotFoundException("File Not Found.", tmpPath);

    if (File.Exists(finalPath))
        File.Delete(finalPath);

    File.Move(tmpPath, finalPath);
}

private static void DeleteTempFileIfExists(string tmpPath)
{
    if (!File.Exists(tmpPath))
        return;

    try
    {
        File.Delete(tmpPath);
    }
    catch
    {
    }
}

// ================= Read =================
public static List<T> ReadSync<T>(string path, IBinarySerializer<T> serializer)
{
    EnsureInitialized();
    if (!File.Exists(path)) return new List<T>();

    var fileLock = GetFileLock(path);
    fileLock.Wait();

    try
    {
        return ReadCore(path, serializer, CancellationToken.None);
    }
    catch (Exception ex)
    {
        LogUtil.Log($"LocalData ReadSync Error: {ex}".Color(Color.red));
        return new List<T>();
    }
    finally
    {
        fileLock.Release();
    }
}

public static async UniTask<List<T>> ReadAsync<T>(string path, IBinarySerializer<T> serializer, CancellationToken token)
{
    EnsureInitialized();
    if (!File.Exists(path)) return new List<T>();

    var fileLock = GetFileLock(path);
    await fileLock.WaitAsync(token);

    try
    {
        await UniTask.SwitchToThreadPool();
        token.ThrowIfCancellationRequested();

        return ReadCore(path, serializer, token);
    }
    catch (OperationCanceledException)
    {
        return new List<T>();
    }
    catch (Exception ex)
    {
        LogUtil.Log($"LocalData ReadAsync Error: {ex}".Color(Color.red));
        return new List<T>();
    }
    finally
    {
        fileLock.Release();
        await UniTask.SwitchToMainThread();
    }
}

private static List<T> ReadCore<T>(string path, IBinarySerializer<T> serializer, CancellationToken token)
{
    using var fs = new FileStream(path, FileMode.Open, FileAccess.Read, FileShare.Read);
    using var br = new BinaryReader(fs);

    int count = br.ReadInt32();
    if (count < 0)
        throw new InvalidDataException($"Invalid item count: {count}");

    var list = new List<T>(count);
    for (int i = 0; i < count; i++)
    {
        token.ThrowIfCancellationRequested();
        list.Add(serializer.Read(br));
    }

    return list;
}
```
